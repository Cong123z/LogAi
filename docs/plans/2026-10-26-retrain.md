# Retrain Implementation Plan

> **Team workflow** (docs/TEAM_WORKFLOW.md): Opus = tech lead (briefs, rulings, final review, merge);
> every task implemented by a Claude **Sonnet 5.5** subagent in its own worktree; every branch reviewed by a
> **fresh Sonnet** subagent before the tech lead's final review. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Fix the reader and template bugs and move Baseline/Review to Catalog first; then a Retrain page: a
status line, a Run details panel (steps with times and detail lines, a progress bar in the current step, the
run's warnings, Cancel), a one-line schedule, history, and one **Run retrain** button (Rebuild, or Re-read by
services, days, hours).

**Spec:** docs/specs/2026-10-26-retrain.md. **Mockup (approved):** https://claude.ai/artifact/VdaHzwwbkVPkWYDMAofnsa

**Tech Stack:** Python 3.11, Flask, psycopg 3, Postgres 16, Elasticsearch 8 client, vanilla JS, pytest.

**Per task:**

1. Tech lead writes `docs/tasks/<id>-<slug>.md` from `docs/templates/task-brief.md` just before dispatch (later
   briefs name the interfaces the merged code actually has) and commits it on master.
2. `git worktree add ../logai2-task-<id> -b task/<id>-<slug> master`.
3. Dispatch Sonnet (`Agent`, `model: sonnet`, background): brief path, PR file path, "reply DONE <sha> or
   QUESTION". Answers via `SendMessage`; each answer is a `Ruling:` line in `.team/ledger.md`.
4. On DONE: dispatch a **fresh** Sonnet reviewer (brief + PR file + `git diff master...task/<id>-<slug>`):
   `Spec ✅/❌`, Critical / Important / Minor, `Approved | Needs fixes`. Up to 3 fix rounds with the implementer.
5. Tech lead final review: seams (transactions, units, contracts), full suite on the branch, docs updated, no
   attribution, scope = the brief's files. Then `git merge --no-ff` with the PR summary, suite on master, remove
   the worktree and branch. The user gave a standing go for merges in this build (2026-10-26).
6. After the last merge: `graphify update .` in `~/Documents/logai2`; agents.md entry.

## Global Constraints (every brief repeats them)

- Tests: `.venv/bin/pytest -q` against the test Postgres on 127.0.0.1:5433 (`docker compose up -d postgres`).
- Tests first: see them fail, then code. Full suite passes before DONE.
- Stage by explicit path; no AI attribution in commits. Never push, merge, rebase or delete branches.
- Never touch `~/Documents/logai-engine` or containers.
- Each task updates the docs it changes (`ARCHITECTURE.md`, `docs/WEB_UI.md`, `README.md`, `docs/BUGS.md`).
- Web never talks to ES. No new dependencies. Code reads like the code around it.

**Files:** `logai2/reader/reader.py`, `logai2/reader/es_source.py`, `logai2/engine.py` (`_select_indices`, `start`,

tests `tests/test_reader.py`, `tests/test_es_source.py`, `tests/test_engine.py`, `tests/fakes.py`.

- `EsSource.page(target, from_ms, upper_ms)`: `target` is a search expression (pattern plus exclusions);
  `_FILTER_PATH` adds `hits.hits._index`.
- Reader state keyed by **pattern**; dedup key `(_index, _id)`; watermark, caught_up, failing as today, per pattern.
- **Overlap rule (Ruling R1):** selection entries in order; a later pattern searches `"<P>,-<earlier>,..."` so
  every index is read once (ES multi-target exclusion). Floor per pattern: `bootstrap.since` if added before
  `bootstrap.until`, else `added_at`.
- **Upgrade (Ruling R2):** no migration. `es_cursors.index` holds the pattern. A pattern with no saved row
  starts at `max(floor, min(since_ms of all saved rows))` when rows exist (old per-index rows all hold the
  boundary), else at its floor. Old rows are deleted by the next flush as today.
- A pattern matching no index is caught up (B8 changes: detection can turn on; status warning
  `no index matches <pattern>`).
- Status `indices` keyed by pattern (`{pattern: {pos_ms, caught_up, failing, floor}}`); `resolution` stays.
- Tests: `test_new_daily_index_first_minute_counted`, `test_one_search_per_pattern_per_poll`,
  `test_dedup_same_id_two_indices`, `test_overlapping_patterns_read_once`, `test_upgrade_from_index_cursors`,
  `test_empty_pattern_caught_up_with_warning`; existing reader tests ported.

## Phase 2: engine

### 54 Migration 008 + Rebuild recorded as runs

**Files:** `logai2/migrations/008_retrain.sql`, new `logai2/jobs/runs.py`, `logai2/jobs/commit.py`, `logai2/engine.py`
(`_commit`, `_run`, `start`), tests `tests/test_db.py`, new `tests/test_runs.py`, `tests/test_engine.py`.

```sql
CREATE TABLE retrain_runs (id bigserial PRIMARY KEY, kind text NOT NULL, trigger text NOT NULL,
  scope jsonb NOT NULL DEFAULT '{}', state text NOT NULL, started_at timestamptz NOT NULL DEFAULT now(),
  finished_at timestamptz, pos_ms bigint, steps jsonb NOT NULL DEFAULT '[]', result jsonb NOT NULL DEFAULT '{}',
  error text, error_type text, failed_step text, log jsonb NOT NULL DEFAULT '[]');
CREATE INDEX ON retrain_runs (started_at DESC);
CREATE TABLE index_services (pattern text NOT NULL, service text NOT NULL, PRIMARY KEY (pattern, service));
```

- `runs.start(conn, kind, trigger, scope) -> int`, `runs.step(conn, id, key, label, detail, finished=False)`,
  `runs.finish(conn, id, state, result=None, error=None, error_type=None, failed_step=None)`.
- `RunLog(logging.Handler)`: while a run is active, keeps WARNING+ lines `{ts, level, logger, message}` (max 50),
  written to `retrain_runs.log` at each step and at finish.
- `commit(conn, cfg, today, rebuild=True)`; result adds `rows_before`. Rebuild steps: `mark` (days marked),
  `rebuild` (rows before -> after), `housekeeping` (partitions, retention).
- Triggers: `schedule`, `manual` (`recompute_baseline`), `startup` (missed), `first_start`. A failure records
  `error`, `error_type`, `failed_step` and re-raises as today. Runs older than 365 days deleted in housekeeping.
- Tests: `test_migration_008`, `test_rebuild_run_recorded`, `test_failed_rebuild_records_error_and_step`,
  `test_run_log_keeps_warnings`, `test_old_runs_deleted`.

### 57 Re-read lane

**Files:** new `logai2/jobs/reread.py`, `logai2/owner/owner.py` (lane hours in `flush`), `logai2/engine.py`
(commands `retrain_run`, `retrain_cancel`, `retrain_estimate`; tick budget), `logai2/config.py`
(`retrain.tick_seconds` 1.0, `retrain.es_timeout_seconds` 30), `README.md`, tests `tests/test_reread.py`.

- `Scope(services: list[str] | None, days: list[date], hour_from: int, hour_to: int)`;
  `clamp(scope, es_oldest, owner_hour_ms) -> (spans, not_in_es_hours)`.
- Patterns read = selected patterns with an `index_services` row for a chosen service.
- Lane: own `OpenMinutes`, shared `Miners` and `KnownLines`, closes **whole hours**; runs only when live is
  caught up, `retrain.tick_seconds` per tick; ES errors: 3 tries, then fail.
- Owner flush per lane hour: `DELETE` the hour's `service_hours`, `hourly_counts`, `template_module_hours` rows
  for the service, insert the lane's, `error_samples` only if the hour had no row, `UPDATE retrain_runs` (pos_ms,
  steps) in the same transaction. `ensure_partitions(first day, today)` at start.
- Steps: `scope` (services, hours chosen, not in ES, to read), `partitions`, `read` (docs read / target, hours
  replaced / total, new templates, rate, position, live lag, pct, eta), `rebuild`. End: Rebuild, `succeeded`;
  cancel: `cancelled`, no Rebuild; failure: `failed`, no Rebuild; restart: resume from `pos_ms`.
- One run at a time: `retrain_run` while one runs -> command result `{"error": "a retrain is running"}`.
- Tests: `test_reread_equals_live_counts`, `test_reread_never_writes_hours_not_in_es`,
  `test_reread_stops_before_owner_hour`, `test_reread_replaces_whole_hour`, `test_reread_crash_resumes_exact`,
  `test_reread_cancel_keeps_done_hours_no_rebuild`, `test_reread_es_error_fails_with_step`,
  `test_reread_index_deleted_midway_warns`, `test_lane_waits_while_live_lags`, `test_second_run_rejected`.

### 60 Truth and stress

**Files:** `scripts/stress_pipeline.py` (scenarios `R1`-`R4`), `docs/perf/2026-10-26-retrain.md`, `docs/BUGS.md`.

- R1: 6 synthetic days, live from day 6, re-read days 1-5: `hourly_counts` and `baseline` equal a full live run.
- R2: re-read under 10k ev/s live: lag < 60 s, no late counts.
- R3: kill the engine at 30 % and 70 %: rows exact.
- R4: index deleted at 50 %: warning, no zeros.

## Review Focus (tech lead, every merge)

- A re-read hour equals what live would have stored.
- Crash mid re-read: nothing doubled, nothing lost.
- No row written for an hour before the oldest ES doc.
- New daily index read from its first doc; overlapping patterns read once; upgrade does not re-read history.
